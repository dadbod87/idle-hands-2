Run automated browser audition tests with muted output: real controller/AudioContext/buffer/gain behavior can be inspected without unexpectedly playing office speakers. Record this explicitly; passing graph state and numerical waveforms are not a physical hearing test. Protect quick Play/Pause, place changes, late resume/decode errors and hidden-page races with generation guards; at most one theme plus one preview accent should remain active. No live-region chatter for every playback tick. A shared Play control and large place choices should make the first action obvious.

Reproducibility should not require a new package/service. If floating-point generation is chosen instead, verify actual regeneration on the pinned Linux runner rather than assuming byte identity across platforms. Record output hashes, source hashes, per-file durations/bytes, finite values, peak/RMS/DC, and zero attack/release edges. Keep artistic listening acceptance distinct.
