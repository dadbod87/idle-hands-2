# Bring the orchard into shared practice

The browser practice pantry establishes the first useful loop, scale, reachable tree stations and paced recipe. Its local record stays local. Shared practice needs its own server-confirmed pantry before residents can reliably bring prepared food to town projects or assist a coworker.

Use one private pantry per resident. Keep apples, snack stock, three independent branch deadlines, the current parcel and cumulative tastings together. Read it through the existing coherent private snapshot, with an absent pantry representing an empty first visit. Start from the current server-authorized player position and server time. Use the same pure orchard rules, with the transaction holding the existing player command lock. Record the reviewed request ID, exact outcome and revision with stock changes. Returned receipts and the snapshot must still agree after a lost reply or process restart. Keep a rendering cue conditional on a fresh successful pick. A peer picking their own apple adds no shared invalidation.

Prefer a dedicated private row joined into the existing snapshot read, with no extra query on idle reads and no new global project lock. Compare that against the lighter schema option of an additive nested save field. Changing the established workshop version would require exercising every existing command adapter, old save loader and allocation check. No existing save should be projected into an older reducer. An unknown pantry version or invalid ledger must leave its original record intact.

Test two residents simultaneously picking the same branch, two competing tabs for one resident, ruined or expired request IDs, wrong room and a tree approached from behind, cooldown boundaries, lost/duplicate acceptance, server restart, full stock, storage preservation and an unchanged read count under idle and public-activity load. Use only fictional residents with disposable PostgreSQL fixtures, and keep existing saved services stopped. Measure the actual shared recipe before making prepared food tradeable or adding score, healing, bonuses or party rewards.
