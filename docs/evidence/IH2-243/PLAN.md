# IH2-243 · Find a neighbor by name or address

The street directory keeps its existing street buttons and offers a separate search for the front door of a known neighbor. Browse six matching occupied homes at a time, or narrow the list by name, address or neighborhood number. The result identifies the actual address, including the district when two residents have the same name. Pressing Enter from the search moves focus to the first matching result. The visit begins only when the player chooses that result.

The action uses the existing front-door route and permission checks. Looking up a name requests no shared work or movement. A stale listing or different signed-in resident cannot start another household's visit from the old button. Ownership, access, public fields, furniture and work remain governed by their current rules.

The first short test caught a result hidden by the sticky title and the first 320px doubled-text test caught horizontal overflow. The final directory reveals the focused result beneath the title, uses the existing frame-aligned text update and keeps the address readable. The tests check the whole target at desktop, 320px, 320px with 200% text and short enlarged landscape. The phone captures show both same-name rows with different addresses. For 320px doubled text the single-line search field retains normal browser horizontal editing.

Three cases passed in Chromium and three in WebKit. The dedicated regression selects the correct duplicate name in another district, refuses a listing changed by an incoming snapshot, sends one existing neighborhood transition and one existing house entry, and preserves the fictional workshop. It uses intercepted fictional login, public snapshot, event stream, movement and command replies. It exercises the real browser layout and route solver. Connected database, permissions and final hosted gates remain separate.

The design cue is visitability and seeing a neighbor's creative work. [Palia’s Home Tours announcement](https://palia.com/news/patch-182) uses published plots as destinations. [Nintendo’s island visits](https://animalcrossing.nintendo.com/new-horizons/share/) describe deliberate visits for exploration and inspiration. A follow-up playtest can have two residents with equally named streets find and visit one particular home, then ask which decoration they noticed. The directory introduces zero participation rewards or ranking.
