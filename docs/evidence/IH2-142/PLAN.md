# See work on the bench

A resident walking into the workshop can see a small piece of timber while the ordinary bench runs, and a finished planter or repair-kit crate when it completes. The paper card says In progress or Finished. The bench goes back to its ordinary surface after collection. This gives players a world cue without opening a menu or adding another HUD timer.

Draw only the confirmed job, using the same clock the bench already uses. An unresolved local write leaves the prior confirmed bench visible. The existing crafting menu still shows details, capacity and the deliberate collection action. This phase changes no recipe, bag value, time, scene collision or authority.

The successful case uses separate synthetic starting feet and stock created by ordinary model gathering, then performs the real first craft and waits five real seconds on desktop, at 320 px phone width and at short 200% text. The planter is visible before ownership changes. Explicit collection removes the world piece and adds exactly one item. The other case forces a quota failure and proves the world still shows no confirmed piece and the stored workshop stays byte-for-byte. No API responses are intercepted; the quota failure is an intentional isolated fixture.
