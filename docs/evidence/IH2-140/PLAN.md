# Choose a browser resident

The field guide in browser practice offers Edit your resident. Choose one existing illustrated look and a display name, then save deliberately. A keyboard user can choose the same appearance and submit from the name field. The resident and name persist on reload in that browser. Closing a draft leaves both the actor and saved preference unchanged.

The local record is a separate versioned preference. It never writes to the workshop save, position, inventory, scores, recipes, clothing ownership, or a shared profile. A failed or unrecognized preference save keeps its prior bytes. Another tab's saved appearance is shown from the actual stored value, and a stale editor must reopen before saving over it. Browsers with Web Locks serialize writes; a synchronous expected-record check remains for other browsers. This preference is independent of the future shared profile and room checkpoints.

The focused domain and actual-browser checks cover validation, save failure, effects of cancellation, exact preservation of unrelated storage, reload and a stale second tab.
