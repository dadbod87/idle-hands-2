# Let Jun suggest one orchard errand

After orientation, or when someone already has orchard progress, Jun can suggest one useful trip. The card uses the confirmed pantry. It can point to a ripe branch, the packing table or the café parcel shelf. While a snack packs, it can suggest the allotment. It leaves the original early orientation advice in place for a new resident. An optional card keeps the ordinary conversation useful for players who came about the bridge.

The buttons use existing named walks from the current room, including the dynamically available orchard branches. The resident must still walk the route. Picking, packing, collection and gifts keep their existing confirmation and timing. Jun issues no apple, snack, badge or progress change.

Three pure checks cover the first apple, the next ripe branch, packing, the exact collection boundary, tasting and the shared-only café suggestion. A native 320-pixel Chromium case starts a fictional resident beside Jun with one apple in a valid local pantry. It taps the suggested branch, walks the actual route and opens the branch with the same pantry bytes. Its test never uses a game API or a saved preview database.

Future optional errands should use the same shape of useful route and brief reason. Avoid adding another permanent quest panel or another timer just to tell the player where to go.
