# IH2-201 · Save a neighbor’s address

Guests can save or remove an address from a visited home’s Address & house details. Saved places are listed at the street directory and reachable through Places in the square or neighborhood once an address exists. Choosing one uses the existing walk and house-entry route. It is a way back to a house you liked, with the real door still part of the trip.

The preference belongs to the current fictional resident and this browser. It records only stable plot IDs, uses the same browser save coordination as other preferences, and displays the current public address and occupant. Missing plots stay off the list. The save and remove controls issue no town command and cannot edit the host’s home. The ordinary visitor and house-entry authority still applies on the return route.

Local browser coverage uses declared fictional shared snapshots and an isolated arrival at the directory. It checks guest and owner scoping, saving, removing, reloading, the directory and Places shortcut, and departure using the existing walk route at desktop, narrow touch and short landscape. The browser saves apply solely to the disposable test context. Hosted acceptance is pending on the independent branch `feat/saved-home-addresses`.

Terra 6.1 verified desktop, 320px and short landscape. Address text and the revisit action remain readable, with ordinary district controls reachable by scrolling on short screens.
