# IH2-202 · Hide empty Bag slots

Keep the existing pockets and make it easier to scan the contents on a narrow phone. An optional Hide empty slots checkbox filters zero-quantity slots in the current pocket. Unknown quantities stay visible. Equipment keeps the lesson and appearance controls available. Moving stacks shows the entire pocket and restores the filter when moving ends.
